## এই মাসের লক্ষ্য
- ফাঁকা editor-এ **প্রথম লাইন** লিখতে আর দ্বিধা থাকবে না (Loop Template, ৬টা মৌলিক কাজ)।
- যেকোনো code-এর **time ও space নিজে হিসাব** করতে পারবে।
- String, Array, Object-এর সব গুরুত্বপূর্ণ method, তাদের খরচ আর ফাঁদ জানবে।
- **Hashing (Map/Set)** — সবচেয়ে বেশি ব্যবহৃত interview অস্ত্র — স্বাভাবিক হয়ে যাবে।
- Closure, `this`, Class দিয়ে নিজের data structure বানাতে পারবে।
- Sorting algorithm নিজে লিখতে আর তুলনা করতে পারবে।
